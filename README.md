## Description
A lightweight Python utility for generating random text such as strings, sentences, or placeholder content.  
Useful for testing, prototyping, or generating dummy data.

## Quick Start
```bash
# Clone the repository
git clone https://github.com/NaipanAbdinegara-git/python-random-text.git

# Move into the project
cd python-random-text

# Run the script
python random_generator.py
````
